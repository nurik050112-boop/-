# Monster Chase Parkour

2D browser parkour runner. The hero runs through a moving gray city map while a huge monster chases from behind and eats the map.

## Features

- Main screen with level select
- Hero and monster skin switching
- 100 generated levels
- Increasing speed, obstacle density, and chase pressure
- Gravity flip gates
- Gaps, spikes, crates, walls, sharp turns, and small charging monsters
- Animated hero run cycle and animated monster bite/chew

## How To Play

- Move: `A` / `D` or left / right arrows
- Jump: `W`, up arrow, or `Space`
- Slide: `S` or down arrow
- Pause: `Esc` or `II`
- Restart: `R` button

Avoid crates, spikes, walls, gaps, turns, and small monsters. Red gravity gates flip the hero to the ceiling or back down. Reach the finish flag before the monster catches the hero.

## Run Locally

Open `index.html` directly in a browser, or start the local server:

```powershell
node server.js
```

Then open:

```text
http://localhost:3000
```
