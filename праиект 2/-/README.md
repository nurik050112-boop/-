# Возрождение Европы

Статическая 2D-браузерная викторина: 20 вопросов по 15 секунд, четыре варианта ответа, сюжетные реплики в виде титров и панорама города, которая восстанавливается за правильные ответы.

Открой `index.html` в браузере для локального запуска. Для публикации на Vercel используй эту папку как корень проекта; сборка и серверные настройки не нужны.
